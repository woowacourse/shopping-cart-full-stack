# 3단계 요구사항 명세서

## 1. 기능 요구사항

| 요구사항 | 사용자 행동 | 설명 | 예외 |
| --- | --- | --- | --- |
| 주문 확인 페이지 이동 | 장바구니 페이지에서 `주문 확인` 버튼 클릭 | 선택된 상품 목록을 기준으로 최대 할인 쿠폰 조합이 자동 적용된 주문 정보를 생성하고 주문 확인 페이지로 이동한다. | 주문 정보 생성 요청 실패 시 에러를 표시하고 페이지를 이동하지 않는다. |
| 쿠폰 목록 조회 | 주문 확인 페이지에서 `쿠폰 적용` 버튼 클릭 | 사용자가 보유한 쿠폰 목록을 조회한다. 사용할 수 있는 쿠폰은 선택 가능하고, 사용할 수 없는 쿠폰은 비활성화한다. | 쿠폰 목록 조회 실패 시 에러를 표시한다. |
| 쿠폰 선택 | 쿠폰 목록 모달에서 쿠폰 체크박스 클릭 | 사용자는 최대 2개의 쿠폰을 선택할 수 있다. 쿠폰을 선택할 때마다 서버에 할인 금액 미리보기 계산을 요청한다. | 미리보기 계산 요청 실패 시 선택 상태와 할인 금액을 이전 상태로 롤백한다. |
| 쿠폰 적용 | 쿠폰 목록 모달에서 `사용하기` 버튼 클릭 | 서버는 선택된 쿠폰이 유효한지 다시 검증한 뒤 주문 정보에 쿠폰을 적용한다. | 유효하지 않은 쿠폰이면 에러를 표시하고, 쿠폰 선택 상태를 초기화하며 모달을 유지한다. |
| 쿠폰 적용 취소 | 쿠폰 목록 모달에서 `X` 버튼 클릭 | 모달을 닫으면 변경 중이던 쿠폰 선택 상태를 버리고, 이전에 적용된 쿠폰 상태를 유지한다. | 없음 |
| 배송 정보 변경 | `제주도 및 도서산간 지역` 체크박스 클릭 | 선택한 배송 정보에 따라 서버가 배송비와 쿠폰 할인 금액을 다시 계산한다. | 요청 실패 시 에러를 표시하고 배송 정보 선택 상태를 이전 상태로 롤백한다. |
| 결제 금액 확인 | 쿠폰 적용 또는 배송 정보 변경 시 | 주문 예정 상품을 기준으로 주문 금액, 쿠폰 할인 금액, 배송비, 총 결제 금액을 확인할 수 있다. | 없음 |

## 2. 상태 및 책임 설계

- 상품 정보, 주문 상품 수량, 적용된 쿠폰, 배송 정보는 서버의 주문 정보를 기준으로 관리한다.
- 주문 생성 시 서버는 적용 가능한 쿠폰 조합 중 할인 금액이 가장 큰 조합을 자동 적용한다.
- 쿠폰 모달에서 체크박스로 선택 중인 `couponIds`는 실제 적용 전까지 클라이언트 상태로 관리한다.
- 쿠폰 적용 버튼을 누르기 전까지 서버의 주문 정보에는 반영하지 않는다.
- 쿠폰 할인 금액과 배송비는 서버가 계산한다.
- 클라이언트는 서버가 내려준 주문 금액, 쿠폰 할인 금액, 배송비를 화면에 표시한다.
- 총 결제 금액은 다음 값들을 기준으로 클라이언트에서 파생 상태로 계산한다.
    ```
    총 결제 금액 = 주문 금액 - 쿠폰 할인 금액 + 배송비
    ```

## 3. 쿠폰 및 금액 계산 정책

### 3-1. 주문 금액
- 주문 금액은 주문 상품들의 `productPrice * quantity` 합계로 계산한다.
- 주문 금액은 쿠폰 할인과 배송비가 적용되기 전 금액이다.

### 3-2. 배송비
- 기본 배송비는 3,000원이다.
- 주문 금액이 100,000원 이상이면 기본 배송비는 0원이다.
- 제주도 및 도서산간 지역을 선택하면 추가 배송비 3,000원이 붙는다.
- 주문 금액이 100,000원 이상이어도 제주도 및 도서산간 지역을 선택하면 추가 배송비는 붙는다.
- `FREESHIPPING 쿠폰`이 적용되면 기본 배송비와 도서산간 추가 배송비를 모두 0원으로 처리한다.

### 3-3. 쿠폰 공통 정책
- 쿠폰은 최대 2개까지 동시에 적용할 수 있다.
- 만료일이 지난 쿠폰은 적용할 수 없다.
- 서버는 쿠폰 적용 가능 여부와 할인 금액을 계산한다.
- 쿠폰을 선택할 때마다 서버에 할인 금액 미리보기 계산을 요청할 수 있다.
- 쿠폰을 실제 적용할 때 서버는 선택된 쿠폰이 여전히 유효한지 다시 검증한다.

### 3-4. 쿠폰별 정책

#### FIXED5000
- 최소 주문 금액은 100,000원이다.
- 주문 금액이 100,000원 이상이면 5,000원을 할인한다.
- 주문 금액이 100,000원 미만이면 적용할 수 없다.
- 만료일은 2026-11-30이다.

#### BOGO
- 동일 상품을 2개 이상 구매하면 적용할 수 있다.
- 적용 가능한 상품이 여러 개라면 단가가 가장 높은 상품 1개 가격만큼 할인한다.
- 동일 상품 수량이 2개 미만이면 적용할 수 없다.
- 만료일은 2026-06-30이다.

#### FREESHIPPING
- 최소 주문 금액은 50,000원이다.
- 주문 금액이 50,000원 이상이면 기본 배송비와 도서산간 추가 배송비를 모두 0원으로 처리한다.
- 주문 금액이 50,000원 미만이면 적용할 수 없다.
- 만료일은 2026-08-31이다.

#### MIRACLESALE
- 오전 4시 이상, 오전 7시 미만에만 적용할 수 있다.
- 적용 가능 시간에 주문하면 정액 할인 쿠폰 적용 후 남은 상품 금액의 30%를 할인한다.
- 적용 가능 시간이 아니면 적용할 수 없다.
- 만료일은 2026-07-31이다.

### 3-5. 복합 쿠폰 계산 순서
- 서버는 적용 가능한 쿠폰 조합 중 최대 2개까지 조합을 만든다.
- 각 조합의 할인 금액을 계산한 뒤, 할인 효과가 가장 큰 조합을 선택한다.
- 정액 할인 쿠폰을 먼저 적용한 후, 정율 할인 쿠폰을 적용한다.
- 정율 할인 쿠폰은 정액 할인이 적용된 후 남은 상품 금액을 기준으로 계산한다.
- 배송비 할인 쿠폰은 상품 할인 금액과 별도로 배송비에 적용한다.
- 상품 할인 금액은 주문 금액을 초과할 수 없다.

## 4. 예외 및 롤백 정책
- 쿠폰 미리보기 계산 요청이 실패하면 쿠폰 선택 상태와 할인 금액을 이전 상태로 되돌린다.
- 쿠폰 적용 시점에 선택된 쿠폰이 유효하지 않으면 에러를 표시하고 쿠폰 목록을 다시 조회한다.
- 쿠폰 적용 실패 시 서버의 주문 정보는 변경하지 않는다.
- 배송 정보 변경 요청이 실패하면 배송 정보 선택 상태를 이전 상태로 되돌린다.
- 주문 정보 생성 요청이 실패하면 주문 확인 페이지로 이동하지 않는다.
