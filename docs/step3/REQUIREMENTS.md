## 장바구니 3단계 - 시스템 설계

### 데이터 및 상태 관리

### DB에서 관리하는 데이터

- 상품 (id, 상품 이름, 금액, 썸네일)
- 장바구니 (상품 id, 수량)
- 쿠폰 (id, 쿠폰 코드, 쿠폰 이름, 만료일, 최소주문금액?, 사용 가능 시간?)
- 주문 정보 (id, 상품id와 수량, 도서 산간 지역인지, 선택된 쿠폰)
- 배송비 (기본 배송비, 도서 산간 배송비)

#### 서버에서 관리하는 데이터

- 금액 요약 정보(주문금액, 쿠폰 할인 금액, 배송비) 계산
- 쿠폰 사용 가능 여부

#### 클라이언트에서 관리하는 데이터

- 장바구니에서 선택한 상품 ID 목록
- 쿠폰 적용하기 팝업에서 선택한 쿠폰 정보

### 비지니스 정책

#### 쿠폰 정책

- 5,000원 할인 쿠폰 (FIXED5000)
  - 사용 가능 조건: 최소 주문 금액이 100,000이상인 경우 사용할 수 있다.
  - 할인 적용: 5000원을 할인한다
- 2+1 쿠폰 (BOGO)
  - 사용가능조건: 동일 상품의 주문 수량이 3개 이상인 경우 사용할 수 있다. 여러 상품이 조건을 충족하면 가장 가격이 높은 상품에 적용한다.
  - 할인 적용: 해당 상품 1개 가격 만큼 할인한다.
- 무료 배송 쿠폰 (FREESHIPPING)
  - 사용가능조건: 최소 주문 금액이 50,000원 이상인 경우 사용할 수 있다. 배송비가 발생하는 주문에만 적용한다.
  - 할인 적용: 배송비 만큼 할인한다.
- 30% 시간제 할인 쿠폰 (MIRACLESALE)
  - 사용가능조건: 한국 표준시(KST) 오전 4시 이상 오전 7시 미만에 사용할 수 있다.
  - 할인 적용: 정액 할인을 먼저 적용한 주문 금액의 30%를 할인한다.
- 모든 쿠폰은 만료일이 지나면 사용할 수 없다.

#### 배송비 정책

- 주문금액이 10만원이 넘으면 무료로 배송한다.
- 도서산간인 경우 배송비가 3000원이 추가된다.

#### 쿠폰 복합 적용

- 쿠폰은 최대 2개까지 선택할 수 있다.
- 주문서 생성시 최대할인효과 쿠폰 2개를 정해서 선택된 쿠폰으로 저장한다.
- 여러 쿠폰 선택 시 정액 쿠폰을 먼저 적용하고 할인된 금액에서 정율 쿠폰을 적용한다.

### 기능 요구사항

#### 쿠폰 선택 및 적용

- [ ] 보유한 전체 쿠폰 정보와 사용 가능한 쿠폰 개수를 확인할 수 있다.
- [ ] 주문에 적용 가능한 쿠폰을 선택할 수 있다.
- [ ] 쿠폰 선택 시 예상 할인 금액을 확인할 수 있다.
- [ ] 쿠폰 적용 후 변경된 금액 요약 정보를 확인할 수 있다.

#### 배송 지역 선택

- [ ] "제주도 및 도서산간 지역" 여부를 선택할 수 있다.
- [ ] 배송 지역 선택 후 추가 배송비가 포함된 금액 요약 정보를 확인할 수 있다.
