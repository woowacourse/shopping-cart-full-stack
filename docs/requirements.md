# 장바구니 미션 기능 요구사항

# 3단계

## 장바구니 페이지

### 상품 선택

- 사용자는 전체 상품을 선택하거나 선택 해제할 수 있다.
- 사용자는 개별 상품을 선택하거나 선택 해제할 수 있다.
- 장바구니 페이지에 진입하면 기본적으로 전체 상품이 선택되어 있다.
- 새로고침을 해도 이전에 선택한 상품 상태가 유지된다.
- 상품 선택 상태는 저장되어야 한다.

### 주문 확인 이동

- 사용자는 `주문 확인` 버튼을 클릭해 주문 확인 페이지로 이동할 수 있다.
- 선택된 상품이 1개 이상일 때만 `주문 확인` 버튼이 활성화된다.

## 주문 확인 페이지

### 주문 상품 확인

- 사용자는 주문한 상품의 종류와 개수를 확인할 수 있다.
- 사용자는 주문한 각 상품의 정보를 확인할 수 있다.

#### 주문 상품 정보

- 이름
- 이미지
- 금액
- 개수

### 배송지 선택

- 사용자는 제주도 및 도서 산간 지역 여부를 체크할 수 있다.
- 제주도 및 도서 산간 지역 여부에 따라 배송비가 반영된다.

### 결제 금액 확인

- 사용자는 주문 금액을 확인할 수 있다.
- 사용자는 쿠폰 할인 금액을 확인할 수 있다.
- 사용자는 배송비를 확인할 수 있다.
- 사용자는 총 결제 금액을 확인할 수 있다.

### 결제 완료

- 사용자는 `결제하기` 버튼을 클릭해 결제 확인 페이지로 이동할 수 있다.
- 결제가 완료되면 주문한 상품은 장바구니에서 비워진다.

## 쿠폰 선택 모달

### 모달 열기

- 사용자는 주문 확인 페이지에서 쿠폰 적용 버튼을 클릭해 쿠폰 선택 모달을 열 수 있다.
- 쿠폰 선택 모달에서는 사용 가능한 쿠폰 목록을 확인할 수 있다.

### 쿠폰 기본 선택

- 주문 확인 페이지에 처음 진입하면 할인율이 가장 큰 쿠폰 조합이 미리 선택되어 있다.
- 쿠폰 선택 모달을 열었을 때 현재 적용된 쿠폰 상태가 표시된다.

### 쿠폰 선택

- 사용자는 쿠폰 선택 모달에서 쿠폰을 선택할 수 있다.
- 사용자는 선택된 쿠폰을 선택 해제할 수 있다.
- 쿠폰은 중복 적용할 수 없다.
- 쿠폰 선택 결과는 주문 확인 페이지의 쿠폰 할인 금액과 총 결제 금액에 반영된다.

### 사용 불가 쿠폰

- 사용할 수 없는 쿠폰은 비활성화 처리한다.
- 비활성화된 쿠폰은 사용자가 선택할 수 없다.

#### 사용 불가 조건

- 5천 원 상품 2개 이하
- 최소 주문 금액 5만 원 미만
- 최소 주문 금액 10만 원 미만
- 오전 4시부터 오전 7시 사이

### 모달 닫기

- 사용자는 닫기 버튼을 클릭해 쿠폰 선택 모달을 닫을 수 있다.
- 사용자는 쿠폰 선택을 완료한 뒤 모달을 닫을 수 있다.
- 모달을 닫아도 선택된 쿠폰 상태는 유지된다.

## 3. 쿠폰

### 3.1 쿠폰 조회

#### 사용 가능한 쿠폰 확인

- **영역**: 쿠폰 선택 모달
- **유저 스토리**: 사용자는 쿠폰 선택 모달에서 사용 가능한 쿠폰을 확인할 수 있다.
- **피처**
  - 쿠폰 조회 API 개발
  - 쿠폰 도메인 개발

- **비고**
  - 첫 진입 시 할인율이 가장 큰 조합의 쿠폰이 미리 선택되어 있다.
  - 사용할 수 없는 쿠폰은 비활성화 처리한다.
  - 쿠폰 비활성화 조건
    - 동일 상품 2개 이하
    - 최소 주문 금액 5만 원 미만
    - 최소 주문 금액 10만 원 미만
    - 오전 4시 ~ 7시가 아닐 때

### 3.2 쿠폰 선택

#### 사용할 쿠폰 선택

- **영역**: 쿠폰 선택 모달
- **유저 스토리**: 사용자는 사용할 쿠폰을 선택할 수 있다.
- **피처**: 쿠폰 선택 API 개발
- **비고**
  - 최대 2개까지 선택할 수 있다.
  - 비활성화된 쿠폰은 선택할 수 없다.

#### 선택 쿠폰 할인 금액 확인

- **영역**: 쿠폰 선택 모달
- **유저 스토리**: 사용자는 선택한 할인 쿠폰에 따른 할인 금액을 버튼 텍스트를 통해 확인할 수 있다.
- **피처**: 쿠폰에 따른 할인 금액 계산 로직 개발
- **비고**
  - 원본 DB를 복사한 임시 DB를 사용해 계산한다.

#### 쿠폰 적용

- **영역**: 쿠폰 선택 모달
- **유저 스토리**: 사용자는 쿠폰 사용하기 버튼 클릭 시 할인된 금액을 적용하고 모달을 닫을 수 있다.
- **피처**
  - 쿠폰 선택에 따른 상태 저장 기능
  - 쿠폰 적용 API 개발

- **비고**
  - 쿠폰 사용하기 버튼 클릭 시 원본 DB를 수정한다.
  - X 버튼 클릭 시 모달을 닫는다.
  - X 버튼 클릭 시 선택한 쿠폰은 적용되지 않는다.
