# 장바구니 2단계

## 프로그래밍 요구사항

- [ ] 상태 관리 훅을 이용하여 상태를 구성한다.
- [ ] 결제 금액과 배송비는 파생 상태로 계산한다.
- [ ] 서버 API 통신 결과를 관리할 수 있는 커스텀 훅을 직접 개발한다.
  - [ ] 반환값에는 데이터, 로딩 여부, 에러 정보 등이 포함되어야 한다.
- [ ] 비동기 요청 상태에 따라 적절한 UI를 보여준다.
- [ ] 에러가 발생한 경우 사용자에게 에러를 알려주는 UI를 표시한다.

---

## 기능 목록

### 1. 장바구니 상품 API 호출

- [ ] API 호출 전에는 스피너를 표시하여 로딩 중임을 나타낸다.
- [ ] 장바구니 API(`/carts`)를 호출한다.

| 상태       | 초기값 |
| ---------- | ------ |
| `loading`  | `true` |
| `products` | `[]`   |

---

### 2. 장바구니 상품 API 응답 처리

- [ ] 응답 결과를 확인하여 에러 여부를 판단한다.
  - [ ] 에러가 발생한 경우, 에러 메시지를 화면 중앙에 표시한다.
- [ ] `{ product: { id, image, name, price }, quantity }` 형태의 응답을 `{ id, image, name, price, quantity }` 형태로 변환한다.

| 상태       | 값                                       |
| ---------- | ---------------------------------------- |
| `loading`  | `false`                                  |
| `products` | `{ id, image, name, price, quantity }[]` |

---

### 3. 장바구니 화면

#### 상품이 없는 경우

- [ ] 장바구니에 담긴 상품이 없다는 안내 화면을 표시한다.

#### 상품이 있는 경우

- [ ] API 응답을 바탕으로 `{ id, image, name, price, quantity }` 형태의 `ProductState`를 구성한다.
- [ ] 상품 이름, 수량, 가격을 화면에 표시한다.

**1. 체크박스 (선택 상태)**

- [ ] 각 상품의 선택 여부를 나타내는 `isSelected` 상태를 `true`로 초기화한다. (기본값: 전체 선택)
- [ ] `isSelected` 상태는 `{ [id]: boolean }` 형식으로 관리한다.
- [ ] 상품을 불러올 때 `localStorage`에서 저장된 선택 상태를 읽어온다(`getItem`).
  - [ ] 저장된 값이 없으면 전체 선택 상태로 초기화한다.
  - [ ] `localStorage`에 저장된 id가 API 응답에 없는 경우 해당 항목을 제거한다.
- [ ] 선택 상태가 변경될 때마다 `localStorage`에 저장한다(`setItem`).
- [ ] 전체 선택 시 모든 `isSelected` 값을 `true`로 변경한다.
- [ ] 전체 해제 시 모든 `isSelected` 값을 `false`로 변경한다.

**2. 수량 변경**

- [ ] 수량이 증가하거나 감소하면 fetch를 통해 서버에 변경 사항을 요청한다.
- [ ] 응답 값을 받으면, 상태를 업데이트 한다.
- [ ] 수량이 99개를 초과할 경우, 최대 99개까지 가능하다는 경고창을 표시한다.
- [ ] 수량이 1개 미만으로 내려갈 경우, 최소 1개까지 가능하다는 경고창을 표시한다.
- [ ] 삭제 버튼 클릭 시 확인 alert를 표시하고, 확인 시 삭제 함수를 호출한다.

**3. 주문 금액**

- [ ] `isSelected`가 `true`인 상품들의 금액만 합산하여 주문 금액을 계산한다.
- [ ] 주문 금액이 10만 원 이상인 경우 배송비를 0원으로 표시한다.
- [ ] 주문 확인 버튼을 표시한다.

---

### 4. 주문 확인 버튼 클릭 후

- [ ] 선택한 상품의 종류 수와 총 수량을 문구로 표시한다.
- [ ] 총 결제 금액을 표시한다.
- [ ] 주문 확인 버튼을 비활성화한다.
